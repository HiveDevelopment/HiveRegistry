# HiveRegistry

HiveRegistry is the official package registry for the HivePanel ecosystem.

It provides a central API for discovering and distributing resources used by HivePanel installations, including:

- 📦 Combs (server templates)
- ☕ Minecraft JAR versions
- 🎮 Game runtimes
- 🐳 Docker image metadata
- 📥 Installation assets

HiveRegistry is completely optional.

Every HivePanel instance can either:

- use the public HiveRegistry,
- host its own private registry,
- or operate entirely offline with locally managed resources.
